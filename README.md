# 📊 TradingU｜投資決策的智慧助理

**TradingU** 是一套專為現代投資者打造的 **股票資訊整合平台**，結合圖表視覺化、自動化資料收集、筆記與研究管理，幫助用戶在資訊爆炸的市場中 **快速聚焦關鍵變化，提升分析效率與精準度**。

我們相信，好的投資決策不該被零散的資訊耽誤。透過整合 **「數據 + 新聞 + 筆記 + 研究」** 於同一畫面，TradingU 讓研究更直觀、更有邏輯。

---

## 🧩 我們解決的痛點

- 📉 僅靠價格圖表，無法理解變動背後的事件  
- 📰 財經新聞與經濟數據難以對應股價走勢  
- 🗒️ 筆記零散、研究重複，缺乏整合效率

打造投資者的智慧工作台，  
**節省整理資訊的時間，放大分析與決策的價值。**
